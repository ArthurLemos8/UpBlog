### UpBlog 📝

O **UpBlog** é uma aplicação web desenvolvida com React e Firebase, com o objetivo de compartilhar ideias, conhecimentos e conteúdos sobre tecnologia e diversos outros assuntos.

🌐 **Acesse o projeto:** https://miniblog-23922.web.app

#### Tecnologias principais utilizadas

- **React** — construção de interfaces baseadas em componentes.
- **JavaScript** — lógica e funcionalidades da aplicação.
- **Firebase Authentication** — autenticação e gerenciamento de usuários.
- **Cloud Firestore** — armazenamento e gerenciamento dos dados.
- **Firebase Hosting** — hospedagem da aplicação.
- **Vite** — ambiente de desenvolvimento e ferramenta de build.

#### Funcionalidades

- Cadastro e login de usuários.
- Criação, edição e exclusão de publicações.
- Busca por conteúdos.
- Gerenciamento de publicações pessoais.
